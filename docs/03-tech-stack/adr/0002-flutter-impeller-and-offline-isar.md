# 🏛 ADR-0002: Flutter (Impeller) + 100% Offline Isar DB

## 1. Контекст
Продукт Vellum требует безупречной типографики, посимвольной заливки чернилами без лагов (120fps ProMotion) и мгновенного старта без интернета. Нативная разработка на Swift/SwiftUI обеспечила бы идеальный доступ к iOS, но закрыла бы путь к кроссплатформенности и потребовала бы дублирования логики Cloze Deletion при выходе на Android. React Native создает мостовой оверхед (Bridge / JSI latency) при обработке быстрых нажатий клавиатуры.

## 2. Решение
Принято решение реализовать клиент на **Flutter 3.x с включенным графическим движком Impeller** и встроенной базой данных **Isar v3**:
1. **Impeller** рендерит графику через Metal на iOS напрямую, компилируя шейдеры на этапе сборки приложения (AOT), что гарантирует отсутствие рывков (jank) при наборе текста.
2. **Isar Database v3** используется как локальное ACID-хранилище стихов и книжечки. Время запроса стиха составляет < 2мс.
3. Полный отказ от удаленного бэкенда для первой версии: все 365+ стихов поставляются в assets бандла.

## 3. Последствия
- **Позитивные:** Нулевые серверные расходы ($0/мес); мгновенная работа в метро и самолете; 120fps рендеринг глифов; возможность сборки под Android одной командой.
- **Негативные:** Размер установочного пакета приложения увеличивается на ~15 Мб за счет встроенного движка Flutter и шрифтов.
