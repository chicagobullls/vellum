# 🏛 ADR-0003: Низколатентный звук SoundPool + CoreHaptics

## 1. Контекст
В Vellum кинестетический опыт набора (звук печатной машинки + щелчок Taptic Engine) является ключевой киллер-фичей. Стандартные аудио-библиотеки мобильных платформ стримят MP3/AAC файлы с диска, что создает задержку 40–80мс. При такой задержке пользователь сначала нажимает клавишу, а звук раздается с опозданием, полностью разрушая ASMR-эффект.

## 2. Решение
1. Использовать несжатые 16-bit 44.1kHz PCM WAV аудиосэмплы микро-размера (10–25 Кб на звук).
2. Загружать сэмплы активной темы печатной машинки в память при старте экрана через **SoundPool (на Android) / AVAudioPlayer pre-warmed buffer (на iOS)**.
3. Вызывать тактильный импульс через нативный MethodChannel `CoreHaptics` синхронно со звуком клика.
4. Достигнутая совокупная задержка: **<= 8 мс**, что находится ниже порога человеческого восприятия задержки.

## 3. Последствия
- **Позитивные:** Мгновенный, физически осязаемый щелчок клавиши; состояние глубокого погружения пользователя.
- **Негативные:** Потребление дополнительно ~4 Мб оперативной памяти под предзагруженные буферы звуков.
