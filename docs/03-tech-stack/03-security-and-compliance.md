# 🛡 Безопасность, конфиденциальность и комплаенс: Vellum

> **Цель документа:** Регламентировать политику Zero-PII приватности, локального шифрования, защиту биллинга в iOS Keychain и соответствие требованиям App Store Review Guidelines и регуляторов (GDPR, 152-ФЗ).

---

## 1. Архитектура нулевого сбора данных (Zero-PII by Design)

Vellum построен на принципе **радикальной приватности**:
- **Без регистрации и паролей:** Приложение не запрашивает email, телефон, имя или привязку соцсетей. Вход происходит мгновенно (Zero-Auth friction).
- **Локальная изоляция данных:** Все набранные стихи, прогресс заучивания, статистика скорости печати и личные заметки хранятся **исключительно в изолированной песочнице (App Sandbox)** устройства пользователя.
- **Apple Privacy Nutrition Label:** В App Store декларируется категория **«Data Not Collected»** (Данные не собираются), что является мощным маркетинговым преимуществом среди думающей аудитории.
- **Соответствие GDPR / 152-ФЗ:** Так как персональные данные не передаются на удаленные серверы, риски регуляторных штрафов полностью исключены.

## 2. Безопасность локального хранилища и iOS Keychain

| Слой данных | Механизм защиты | Спецификация Apple Security |
| :--- | :--- | :--- |
| **Биллинг и статус Pro** | **iOS Secure Keychain** | Класс `kSecClassGenericPassword` с атрибутом доступности `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`. Не подлежит чтению другими приложениями даже при Jailbreak. |
| **База данных Isar** | **iOS Data Protection API** | Шифрование файлов БД на уровне файловой системы APFS с ключом аппаратного анклава `NSFileProtectionCompleteUntilFirstUserAuthentication`. |
| **Служебные ключи сборки** | **Fastlane / GitHub Secrets** | Сертификаты дистрибуции `Apple Distribution Certificate` и ключи `App Store Connect API Key` зашифрованы в GitHub Secrets с использованием OpenSSL/Match. |

## 3. Комплаенс с App Store Review Guidelines

1. **Правило 3.1.2 (Автовозобновляемые подписки):**
   - Экран покупки Vellum Pro отображает: точную стоимость за период, дату списания, условия триала (3 дня бесплатно) и прямые ссылки на Политику конфиденциальности и Условия использования (EULA).
   - Реализована обязательная и доступная в 1 тап кнопка **«Restore Purchases»** (Восстановление покупок).
2. **Правило 5.1.2 (Сбор данных и трекинг):**
   - Приложение **не использует IDFA (Advertising Identifier)** и не вызывает назойливый системный диалог App Tracking Transparency (ATT), что повышает доверие пользователей.
   - Используемая телеметрия (TelemetryDeck) агрегирует только обезличенные сигналы нажатий клавиш без IP-адресов.
3. **Правило 2.1 (Производительность и стабильность):**
   - Отсутствие сетевых зависимостей гарантирует 100% работоспособность при проверке модератором Apple в закрытых тестовых сетях Купертино.

## 4. Юридическая чистота контента (Copyright & Public Domain)

- **Встроенная библиотека:** Все 365+ стихотворений в базе принадлежат к **Общественному достоянию (Public Domain)** в соответствии с Бернской конвенцией (прошло более 70 лет со дня смерти автора на 1 января текущего года).
- **Пользовательский контент (UGC в `FR-09`):**
  - Добавление собственных текстов квалифицируется как **личное некоммерческое использование** (Fair Use).
  - В приложении зафиксирован дисклеймер: *«Пользователь несет единоличную ответственность за соблюдение авторских прав на тексты, добавляемые в личный приватный блокнот»*.
