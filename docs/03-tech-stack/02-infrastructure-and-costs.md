# 💰 Оценка инфраструктуры и расчет затрат: Vellum

> **Цель документа:** Продемонстрировать финансовую устойчивость архитектуры 100% Offline-first, рассчитать расходы на хостинг, сервисы и сторы для стадий 1k MAU и 10k MAU, а также вывести юнит-экономику подписки.

---

## 1. Смета инфраструктуры на стадии MVP (до 1 000 MAU)

Благодаря архитектуре **100% Offline-first** (встроенная база данных Isar и локальные алгоритмы) серверные расходы на обработку данных равны нулю:

| Сервис / Ресурс | Провайдер / Тариф | Назначение | Стоимость ($/мес) |
| :--- | :--- | :--- | :---: |
| **Сервер бэкенда** | *Не требуется* (Zero-Backend) | Локальный клиент | **$0.00** |
| **База данных** | Isar v3 (On-Device Embedded) | Локальное хранение стихов | **$0.00** |
| **CI / CD сборка** | GitHub Actions (Free 2,000 мин) | Автосборка Flutter IPA/APK | **$0.00** |
| **Телеметрия (Zero-PII)** | TelemetryDeck (Hobby Free tier) | Анонимная аналитика событий | **$0.00** |
| **Мониторинг крэшей** | Sentry for Mobile (Developer Free) | Отлов багов и зависаний | **$0.00** |
| **Лендинг и домен** | Cloudflare Pages + Домен `.app` | Сайт-визитка vellum.app | **$1.00** ($12/год) |
| **Apple Developer Program** | Apple ($99 в год) | Аккаунт разработчика App Store | **$8.25** |
| **ИТОГО ИНФРАСТРУКТУРА:** | | | **$9.25 / месяц** |

## 2. Юнит-экономика Vellum Pro (1 000 MAU)

- **Активная база (MAU):** 1 000 пользователей;
- **Конверсия в Vellum Pro:** `4.5%` = **45 платящих подписчиков**;
- **Структура подписок:**
  - 30 пользователей на годовом плане ($19.99/год ➔ $1.66/мес);
  - 15 пользователей на месячном плане ($2.99/мес);
- **Валовая выручка (Gross Revenue):** (30 × $1.66) + (15 × $2.99) = **$94.65 / месяц**;
- **Комиссия Apple App Store (15% Small Business Program):** -$14.20;
- **Чистая выручка (Net Revenue):** **$80.45 / месяц**;
- **Операционные расходы инфры:** -$9.25 / месяц;
- **Чистая прибыль (EBITDA):** **+$71.20 / месяц** (Проект выходит в плюс уже на первой 1 000 пользователей).
- **Валовая маржинальность (Gross Margin):** **88.5%**.

## 3. Масштабирование на 10 000 MAU (Growth Stage)

| Статья | 1 000 MAU | 10 000 MAU |
| :--- | :--- | :--- |
| **Инфраструктурные затраты** | $9.25 / мес | **$29.00 / мес** (TelemetryDeck Pro + Sentry) |
| **Платящие подписчики (4.5%)** | 45 чел | **450 чел** |
| **Чистая выручка (Net MRR)** | $80.45 / мес | **~$805.00 / месяц** |
| **Годовой чистый доход (ARR)** | ~$965 / год | **~$9 660 / год** |
| **Себестоимость на 1 активного пользователя** | **$0.009 / мес** | **$0.0029 / мес** |

### Вывод:
Архитектура Vellum защищена от "смерти от успеха": приток 100 000 пользователей не создаст нагрузки на серверы и не обрушит счета за API токенов. Экономическая модель является сверхмаржинальной и антихрупкой.
