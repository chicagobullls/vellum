# 🎯 Оценка качества AI, бенчмарки и реестр промптов: Vellum

> **Назначение:**  
> Документ регламентирует алгоритмы и NLP-пайплайн кураторской подготовки базы стихов, автоматическое определение стихотворного размера (метр/стопа), выделение рифм для режима «Исчезающих слов» (Cloze Deletion) и проверку авторских прав.

---

## 1. Метрики качества кураторского AI-пайплайна

При формировании встроенного каталога стихов и обработке пользовательских текстов (UGC в `FR-09`) используются автоматизированные метрики:

| Метрика | Что измеряет | Целевой порог (SLO) | Метод проверки |
| :--- | :--- | :---: | :--- |
| **Meter & Rhythm Accuracy** | Точность определения стихотворного размера (ямб, хорей, дактиль, амфибрахий, анапест) | `>= 98%` | Сравнение с эталонной разметкой стиховедческой базы |
| **Rhyme Pair Extraction** | Корректность связывания рифмующихся строк (AABB, ABAB, ABBA) | `>= 96%` | Фонетический сопоставитель (Grapheme-to-Phoneme) |
| **Public Domain Compliance** | Отсутствие авторов, умерших менее 70 лет назад | `100%` | Проверка по базе дат жизни Викиданных / Минкульта |
| **Stress Mark Precision (Ударения)** | Правильность расстановки вариативных поэтических ударений | `>= 99%` | Словарь поэтических ударений (Зарва, Аванесов) |
| **Cloze Deletion Balance** | Баланс удаленных слов (не удаляются предлоги и союзы, скрываются смысловые существительные и глаголы) | `100%` | POS-tagging (Part of Speech) фильтр |

## 3. Реестр системных промптов (Prompt Registry)

### Промпт подготовки Cloze Deletion масок (`PROMPT_CLOZE_ANALYZER_V1`)
```markdown
# ID: PROMPT_CLOZE_ANALYZER_V1
# Model: gemini-1.5-flash / Claude 3.5 Haiku
# Temperature: 0.1
# Output: JSON

SYSTEM:
Вы — эксперт в области классической поэзии и стихосложения. 
Ваша задача — проанализировать стихотворение и сгенерировать маски для 4 уровней заучивания наизусть.

ПРАВИЛА ГЕНЕРАЦИИ МАСОК:
1. Уровень 1: 0% скрытых слов (полный текст).
2. Уровень 2: скрыть 30% слов. Скрывать ТОЛЬКО ключевые существительные и глаголы. НЕ скрывать союзы ("и", "а", "но"), предлоги ("в", "на", "под") и местоимения.
3. Уровень 3: скрыть все слова строк, КРОМЕ финальных рифмующихся слов (чтобы пользователь опирался на рифму).
4. Уровень 4: скрыть 100% слов (полное воспроизведение по памяти).

ВЫХОДНОЙ ФОРМАТ (JSON):
{
  "poem_id": "string",
  "meter": "string",
  "rhyme_scheme": "string",
  "cloze_levels": {
    "level_2": [{"line": 1, "hidden_word_indices": [2, 4]}],
    "level_3": [{"line": 1, "visible_word_indices": [5]}]
  }
}
```
