## 📦 EPIC-02: Экран Daily Sanctuary и движок Ghost Typing (M1)

- **Тип:** Domain / Logic
- **Связи:** `FR-01`, `SCR-01`
- **Оценка:** S (1 день)
- **Acceptance Criteria:**
  - [x] Алгоритм возвращает один и тот же стих в течение дня для выбранной локали (RU/EN).
  - [x] В 00:00 локального времени стих автоматически меняется.
  - [x] Стих содержит от 8 до 20 строк выверенной классики Public Domain.

- **Связи:** `FR-02`, `SCR-01`

  - [x] Активная строка автоматически и плавно центрируется по вертикали экрана.

### `TASK-106`: Обработка ошибок ввода и анимация каретки
