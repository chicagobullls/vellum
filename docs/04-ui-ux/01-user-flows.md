# 🗺 Пользовательские сценарии (User Flows): Vellum

> **Цель документа:** Спроектировать карту навигации мобильного интерфейса Vellum, структуру ключевых экранов (`SCR-01`..`SCR-06`) и логику состояний клавиатуры и фокуса.

---

## 1. Схема основного пользовательского пути (Happy Path Flow)

```mermaid
flowchart TD
    Launch([Открытие приложения Vellum]) --> SCR01[SCR-01: Ежедневный стих дня]
    
    SCR01 --> ActionType[Тап по экрану: активация Ghost Typing]
    ActionType --> TypingState[Набор символов: звук Underwood + Taptic отклик]
    TypingState -->|Завершена последняя строка| Bell[Звонок каретки + Золотое свечение]
    
    Bell --> ActionNext{Выбор действия}
    ActionNext -->|Сохранить| SaveFolio[Сохранение в Книжечку: Isar DB]
    ActionNext -->|Заучить наизусть| SCR02[SCR-02: Режим Cloze Deletion]
    ActionNext -->|Поделиться| SCR04[SCR-04: Экспорт Story Card]
    
    SCR02 --> ClozePractice[Прохождение уровней: 30% -> Рифмы -> Слепая печать]
    ClozePractice --> MasteryComplete[Печать воскового сургуча 'Mastered']
    MasteryComplete --> SCR03[SCR-03: Личный фолиант]
    
    SaveFolio --> SCR03
    
    SCR03 --> OpenSettings[Иконка вензеля] --> SCR06[SCR-06: Настройки и звуковые темы]
    
    subgraph PaywallTriggers [Триггеры монетизации]
        SCR02 -.->|Тап на Уровень 3/4 без подписки| SCR05[SCR-05: Пейволл Vellum Pro]
        SCR03 -.->|Попытка сохранить 16-й стих| SCR05
        SCR06 -.->|Выбор машинки Hermes 3000| SCR05
    end
    
    SCR05 -->|Оплата Apple Pay| Unlocked[Мгновенная разблокировка Pro]
    SCR05 -->|Закрыть| Back[Возврат на предыдущий экран]
```

## 3. Сценарии обработки особых состояний (Edge Cases & Haptics)

1. **Миссклик / Ошибка ввода буквы в Ghost Typing:**
   - Буква не вводится в строку.
   - Символ на миллисекунду вспыхивает приглушенным терракотовым оттенком (`#8B3A2B`) и совершает микро-покачивание (горизонтальный shake на 3px).
   - Раздается глухой механический стук заклинившей литеры (dull mechanical thud) и легкая сдвоенная вибрация.
2. **Переход на следующую строфу:**
   - При вводе последнего символа строки фокус плавно и бесшовно смещается на следующую строку.
   - При завершении четверостишия звучит характерный механический звонок каретки (*typewriter carriage return bell*).
3. **Первый запуск без интернета:**
   - Приложение мгновенно открывает детерминированный стих текущего дня из локального Isar-кэша без экрана загрузки (0 секунд ожидания).
