## 2. Анализ реализуемости (Feasibility Study)

### Техническая реализуемость (Technical Feasibility):
- **Степень зрелости стека:** **Высокая (Flutter 3.x + Impeller Engine)**.
  - Движок Impeller полностью устраняет проблему шейдерных подергиваний (jank) на iOS, гарантируя стабильные 120 fps при анимации символов.
  - Встроенная локальная база данных (**Isar / SQLite**) исключает сетевые сбои, тайм-ауты и зависимость от серверов.
- **Критические зависимости:**
  - Нативная интеграция `audioplayers` / `flutter_sound`.
  - Плагин тактильного отклика `haptic_feedback` (Taptic Engine).
- **Proof-of-Concept (PoC недели 1):** Сборка минимального экрана на Flutter с одним четверостишием, посимвольным заполнением цветом при вводе и синхронным звуком щелчка печатной машинки с задержкой < 10мс.

### Ресурсная реализуемость (Resource Feasibility):
- **Трудоемкость создания MVP:** **4–6 человеко-недель** для одного сильного разработчика (Flutter).
- **Инфраструктурный порог:** **$0 / месяц** (серверы не требуются, все данные хранятся локально на устройстве).
- **Фиксированные затраты запуска:** $99/год за Apple Developer Program аккаунт для публикации в App Store.
